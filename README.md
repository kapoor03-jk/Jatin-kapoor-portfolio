# J Kapoor — Cybersecurity Portfolio

A responsive cybersecurity portfolio website built with plain HTML, CSS and JavaScript.

## Before publishing

1. Put your actual resume PDF in this folder and name it `resume.pdf`.
2. Replace `YOUR_EMAIL@example.com` in `index.html`.
3. Replace the LinkedIn placeholder URL/text.
4. Replace the GitHub placeholder URL/text.
5. Review project descriptions and add GitHub/demo links if available.

## Run locally

Open `index.html` in a browser.

For a local development server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy

The site can be deployed to GitHub Pages, Netlify, Vercel, or another static hosting service.
